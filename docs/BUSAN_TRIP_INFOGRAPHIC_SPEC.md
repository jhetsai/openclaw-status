# 釜山旅遊行程 Infographic 技術規格書

## 1. 參考圖片分析

### 版面結構
- **頂部標題區**：約 15%，含大標題 + 三大特色 + 插圖角色
- **中部行程區**：垂直時間軸結構，每天水平排列，由上而下
- **底部資訊區**：約 15%，四欄佈局（交通/Pass/美食/提醒）

### 色彩配置（Macaron 風格）
```

```

### 字體層級
```
主標題:   28-32px, 粗體, 藝術字型
日期標:   18-20px, 粗體
景點名:   14-16px, 中粗體
描述:     12-13px, 正常
底部標題: 14px, 粗體
底部內容: 12px, 正常
```

### 卡片樣式
- 大圓角 (border-radius: 12-16px)
- 細邊框 (1px solid #E0E0E0)
- 輕微陰影 (box-shadow: 0 2px 8px rgba(0,0,0,0.08))
- 平面化設計，無厚重立體感

### 圖示風格
- Emoji 為主（✈️🚇🍖🏯等）
- 線條插圖用於交通工具
- 可愛卡通角色（旅行 mascot）

### 每天行程呈現
- 横向時間線（➜ 箭頭連接）
- 每站：照片/圖示 + 景點名 + 時間/描述
- 結尾統一「回住宿」標示

## 3. 技術實現方案

### 工具
- **HTML5 + CSS3**（純靜態，無需後端）
- **Flexbox + Grid**（響應式佈局）
- **wkhtmltopdf**（生成 PDF）
- **html2canvas**（生成 PNG）

### 輸出格式
1. **HTML 檔案**：直接在瀏覽器開啟預覽
2. **PDF 檔案**：下載列印或分享
3. **PNG 圖檔**：可用於 LINE/社群分享

### 字體選擇
- 標題：Noto Sans TC（粗體）
- 內文：Noto Sans TC（正常）
- Emoji：系統內建

### 響應式設計
- 針對手機横屏優化（旅遊景點圖片常用横式）
- 桌面電腦可完整顯示
- 可列印 A4 尺寸
