## 🔄 更新機制

- **ESP32 輪詢頻率：** 每 30 秒 HTTP GET 一次 `dashboard.json`
- **OpenClaw 更新頻率：** 每 30 分鐘產生一次 `dashboard.json` 到 R2
- **快取策略：** 若 HTTP 失敗，顯示上一次成功資料
- **超時處理：** 10 秒無回應放棄，繼續用舊資料
