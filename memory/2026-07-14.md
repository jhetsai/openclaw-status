## ESP32 黑屏搶修 + 市值/漲幅循環（下午時段）

### 問題發現
使用者回報 ESP32 燒錄失敗、螢幕無畫面。

### 搶修過程

#### ① sdkconfig BOARD_TYPE 異常（commit: 重新燒錄後修復）
- 序列 log 顯示 `SKU=bread-compact-wifi`（OLED 小板）
- 應該是 `waveshare-s3-touch-lcd-4b`
- 原因：sdkconfig 被某次 idf.py 自動改回 BREAD_COMPACT_WIFI（原因待查）
- 修正：手動 sed 改 sdkconfig:
  - 關掉 `CONFIG_BOARD_TYPE_BREAD_COMPACT_WIFI=y`
  - 開啟 `CONFIG_BOARD_TYPE_WAVESHARE_S3_TOUCH_LCD_4B=y`

#### ② WDT task_not_found 報錯
- `esp_task_wdt_reset()` 在 LvglTask 沒註冊 WDT 時報錯（但不會讓 ESP32 死）
- 修正:
  - LvglTask 開頭加 `esp_task_wdt_add(NULL)` 註冊
  - fetch timer callback 移除 `esp_task_wdt_reset()`（timer 無 task 身份）
  - 結果：WDT errors 58 → 0

#### ③ 市值/漲幅循環功能補回（commit d72df0da）
- 上一版 WDT 修復 commit `666d3b87` 漏掉了 `esp_timer_create(mover_timer_)` 那段
- 新增 `mover_switch_pending_` flag：timer 每 10 秒切換 `mover_mode_`，僅觸發 UI 重繪不重新 fetch
- 結果：`[MOVER] switch to 漲幅` / `switch to 市值` 每 10 秒切換

#### ④ 標題不會變（commit 3c7ac0f9）
- 根因：CreateHomeScreen 內標題 label 是本地變數 `lbl`，沒存到 `lbl_mover_title_`
- UpdateHomeCards 內 `lv_label_set_text(lbl_mover_title_, ...)` 永遠執行 nullptr 檢查失敗
- 修正：`lbl = lv_label_create(card);` → `lbl_mover_title_ = lv_label_create(card);`
