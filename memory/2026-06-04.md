## /sys 修正：OpenRouter Bearer auth（07:39）

**問題**：`/sys` 抓 OpenRouter 月用量回 401 "No cookie auth credentials found"

**根因**：原本的指令列沒帶 Authorization header，OpenRouter 預設去找 cookie session token → 失敗

**修法**：改用 Bearer token 認證
```bash
curl -s -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  https://openrouter.ai/api/v1/auth/key
```
（`$OPENROUTER_API_KEY` 從 `openclaw.json` env 讀）

**驗證**：成功拿到資料
- Limit: $5.00 / 已用: $0.586 / 剩餘: $4.41
- 過期：2027-05-22

**已更新**：`MEMORY.md` `/sys 指令` 段落，加上 Bearer header 說明 + 教訓註記
