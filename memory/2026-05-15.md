## 2026-05-15 晚間更新（20:22）

### 持股總覽網頁問題處理

**問題：HTML tbody 內容是 hardcode 靜態資料，與 us_prices.json 不同步**

1. **一開始上傳錯版本**：R2 上是舊版（16,346 bytes），用戶看到的「名」欄位錯亂
2. **重新上傳正確版本**（23,570 bytes）後，ref 表格的 FNMR 漲跌%仍有問題：
   - us_prices.json 正確資料：現價 2.45，前收 2.54 → 漲跌 -3.54%
   - HTML tbody hardcode 內容：前收當成 2.52 → 顯示 -2.78%（錯誤）
3. **根本原因**：gen_us_prices.py 爬回的 Yahoo Finance `chartPreviousClose` 對 FNMR 這種很冷門的商品可能不太準

### FNMR 數據爭議
- us_prices.json：現價 2.45，前收 2.54（Yahoo Finance chartPreviousClose）
- 蔡哲維表示前收「應該是 2.45」，懷疑資料來源有問題
- 我已用 curl 直接查 Yahoo Finance API，確認 `chartPreviousClose` = 2.54

### 待處理
- 需重新生成 tbody 內容，使用真實的 us_prices.json 計算漲%
- 或確保 JS fetch 時能正確覆蓋 tbody 內容
- 目前 HTML 裡的 ref tbody 是 hardcode，不是 fetch 動態生成的

### 關鍵教訓
- 不能只看 HTML 內容就以為是「正確」——tbody 可能是 hardcode 舊資料
- JS fetch 會用 us_prices.json 的資料動態替換 tbody，但 R2 上的 HTML 可能沒更新
- **需要重新上傳含有正確 tbody 內容的 HTML** 或確保 JS fetch 能完整覆蓋
