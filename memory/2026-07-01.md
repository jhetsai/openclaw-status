- 需要等問題3修復後才能燒新版韌體

**問題3：編譯失敗 - esp_emote_gfx 與 IDF v5.4.2 不相容**
- 錯誤：`esp_log_color.h: error: format '%d' expects argument of type 'int', but argument has type 'uint32_t'`
- 位置：`managed_components/espressif2022__esp_emote_gfx/src/core/gfx_refr.c:117`
- 原因：第三方元件使用 `%d` 格式化 `uint32_t`，IDF v5.4.2 把 `-Wformat` 警告當成錯誤
- 解決方案：
  1. 修改 `components/espressif2022__esp_emote_gfx/CMakeLists.txt`，加 `target_compile_options(${COMPONENT_LIB} PRIVATE -Wno-error=format ...)`
  2. 或修改 `gfx_refr.c` 將 `%d` 改為 `%" PRIu32`
- 現已移動元件到 `components/` 目錄（脫離 managed_components）
