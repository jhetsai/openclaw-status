### 第 7 條規則（待套用）

**問題**：AI 把多個編號項擠在同一段：
```
- **南亞科四大挑戰**: 1. **報價持續下跌**... 2. **DDR5 轉換緩慢**... 3. **競爭壓力大**... 4. **產業下行週期延長**
```

**修法**：改 line 57 的規則
```python
# 原本（壞）
text = _re.sub(r'(\s)([1-9][\.、] \*\*[^*]{1,30}\*\*[:：]?)', r'\n- \2', text)

# 改為（好）— 拆成獨立行讓現有 numbered list regex 接手
text = _re.sub(r'(\s)([1-9][\.、] \*\*[^*]{1,50}\*\*[:：]?)', r'\n\2', text)
```

理由：原本的 `\n- \2` 會把 `1. **xxx**` 包成 `- 1. **xxx**`，變成沒編號的 list，後面的 2./3./4. 都被吞掉。改成純換行後，`1. **xxx**` 是標準 numbered list，正則 `^\d+\.\s+(.+)$` 會自己處理。
